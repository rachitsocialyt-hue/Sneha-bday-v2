# Happy Birthday Sneha ❤️

A 7-page interactive birthday scrapbook made with HTML, CSS and vanilla JavaScript.

## Pages
1. Welcome + background music
2. Interactive beer bottle (tap / phone shake)
3. Interactive cake (swipe knife)
4. Scratch-to-reveal photo
5. Video + handwritten-style birthday letter
6. Photo wall + appreciation
7. Final message + heart animation

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## GitHub Pages
Upload the **contents of this folder** to the repository root, then enable GitHub Pages from Settings → Pages → Deploy from branch.

All assets use relative paths, so no server-side setup is required.

## Notes
- Background music is looped continuously and can be controlled from the top-right button.
- Mobile browsers may block autoplay; the first Start button intentionally starts the music after a user interaction.
- Phone-shake interaction has a tap fallback.
- The video has been compressed for faster loading.
- Images are local assets and use lazy loading where appropriate.
